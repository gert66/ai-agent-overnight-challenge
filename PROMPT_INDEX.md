- `02_Rubik_2x2/PROMPT_AND_ACCEPTANCE.md`

- `04_3D_Path_Planner/PROMPT_AND_ACCEPTANCE.md`
- `05_Maze_Chase/PROMPT_AND_ACCEPTANCE.md`

## Fair-play rule

At launch, the orchestrator receives:
1. `MASTER_PROMPT.md`
2. the selected challenge folder
3. the public/synthetic background material and sample input in that folder

No hidden implementation code is supplied. Human intervention stops after launch unless a genuine safety, authentication or permission barrier makes further progress impossible. All code, tests, commits and final results should remain available for review the next morning.
