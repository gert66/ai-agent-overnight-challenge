# AI Agent Overnight Challenge - Team Share

Deze map is bedoeld als gedeelde achtergrondmap voor de vijf challenge-opties.

Per challenge vind je:
- een korte beschrijving van de opdracht;
- wat als input beschikbaar moet zijn;
- wat morgenochtend zichtbaar moet zijn;
- publieke bronnen die als context mogen worden gebruikt;
- eventuele lokale voorbeelddata.

Belangrijke randvoorwaarden:
- alleen publieke of synthetische data;
- geen patiëntdata of persoonsgegevens;
- geen vertrouwelijke interne informatie;
- geen interne broncode;
- na start geen menselijke interventie, behalve bij echte veiligheids- of autorisatieblokkades.
